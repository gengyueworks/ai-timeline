## 为什么做这条时间轴

这个项目最初是我学习 AI 时记录下来的副产品。

我是一个文科写作者，没有计算机科班背景。我喜欢研究 AI，也喜欢沿着一个概念找到另一个概念，在今天的新系统里看见几十年前论文留下的影子，再把散落在论文、模型、产品和基础设施里的变化，慢慢整理成一张可以行走的地图。

人工智能常常被讲成一连串最近发生的产品发布。它的来路其实穿过数学、控制论、认知科学、神经科学、哲学、计算机工程、基础设施和漫长的低谷，也穿过一群在世界准备好之前就提出想法的人。

时间轴记录的不只是日期。它把论文、模型、产品、算力、机构、行业争论和文化事件放在同一条可追溯的路径上，让读者看见一项突破从哪里来，后来改变了什么，又沿着哪些方向继续生长。

地图总带着画图人的视角。我生活在中国，日常同时阅读中文和英文资料，自然会注意到一些在英文概述里较少出现的开源模型、基础设施和开发者社区。只要它们在技术演化中确实重要，我就把它们和世界其他地方的进展放在一起。这不是替某个国家或公司说话，只是希望这张地图尽可能开放、多元，也诚实地面对自己的观看位置。

## 更大的构想

人工智能时间轴未来不会只是一张更长的事件清单。它希望逐渐成为一个可以进入、连接和探索的公共历史记录，记录一个仍在创造自身的领域。

### 一份值得信任的公共编年史

项目的基础，是一份有明确来源、持续维护、公开修订的 AI 历史记录。每条内容都应该小到可以核查，也足够丰富，能够把读者带向下一段历史。日期很重要，日期之间的联系同样重要。

### 一张人物、观念与系统的地图

AI 史也是人的历史。未来，读者可以沿着一个人的轨迹，看到早期论文、关键合作、进入的实验室、参与的模型、经历的争论，以及这些想法后来汇入历史的位置。

项目也会逐步梳理模型与观念的谱系，例如符号推理如何走向今天的智能体系统，感知机如何延伸至深度神经网络，统计语言方法如何走向基础模型，以及研究思想如何变成基础设施和日常工具。

我们关心两件事，**发生了什么**，以及 **它后来变成了什么**。

### 保存日期之外的历史现场

重要的历史也发生在实验室、工作室、会议室、公开演示、产品发布、深夜实验和正式论文之外的谈话里。随着档案生长，项目可以逐步纳入照片、口述历史、通信、演讲、早期界面、同期报道和亲历者回忆。

当结局还没有变得清晰时，这个领域是什么感觉？技术史同样也是人的历史，我们希望留下一些这样的现场。

### 让档案随着领域一起生长

研究者、工程师、设计师、创业者、档案工作者、学生和普通读者，都可能掌握某一段只有自己熟悉的历史。贡献与纠错可以让档案变得更宽，但不会把它变成宣传名录。

事实层需要证据。文章、视觉叙事、学习路径和编辑选择，则可以在事实之上提供不同的观看方式。

### 一个可以不断发现的历史世界

随着档案扩大，未来可能加入下面这些功能。

- 人物、模型、机构与概念地图；
- 展示同一时期不同地点发生之事的平行时间轴；
- 模型家族树与观念谱系；
- 按学科、国家、机构和主题筛选；
- 带版本号的数据集与公共 API；
- 面向学生、研究者、写作者和普通读者的阅读路径；
- 可用于课堂、文章、展览和研究的引用与导出；
- 不改写事实层、只负责解释历史脉络的编辑文章。

它应该能被阅读五分钟、探索五小时，也能在多年之后继续被引用。

> **让记忆成为基础设施。**

## 现在已经有什么

完整维护库收录 **272 条双语事件**，本仓库公开其中 **116 条代表性记录**。每条公开记录包括下面这些内容。

- 带有精度说明的年份或日期；
- 简明的中英双语标题与摘要；
- 事件为什么重要；
- 相关人物、模型、机构与主题；
- 重要度与置信度信息；
- 至少一个可以公开访问的来源。

公开数据是这项工作的地基。它可以进入教学工具、可视化项目和研究索引，也可以支持新的 AI 历史学习方式。

## 编辑原则

### 来源先于故事

每条记录都应该可以追溯。优先采用一手材料；需要补充语境时，再使用可靠的二手来源。

### 提供语境，不制造神话

时间轴会尽量区分当时发生的事实、这件事的重要性，以及后来叙事附加其上的部分。

### 具体胜过夸张

「革命性」不是历史描述。日期、人物、系统、文件、演示和后果才是。

### 天生具有全球视野

AI 历史发生在许多实验室、公司、国家和语言环境中。档案会继续扩大覆盖范围，但不会把任何单一生态当成整个领域。

### 修订也是历史的一部分

一份活的档案必须允许改变。重要修订应通过来源、版本记录和公开讨论留下痕迹。

## 快速开始

```bash
git clone https://github.com/gengyueworks/ai-timeline.git
cd ai-timeline
python3 -m http.server 8000
```

然后在浏览器访问 http://localhost:8000。

公开数据集保存在 [`ai-timeline-public.json`](./ai-timeline-public.json)，数据结构规范写在 [`ai-timeline-schema.json`](./ai-timeline-schema.json)。

## 参与贡献

欢迎提交纠错或新增事件建议。一条建议应当包括下面这些信息。

1. 日期与日期精度；
2. 对事件的简明说明；
3. 它对 AI 历史整体为什么重要；
4. 至少一个可靠的公开来源；
5. 相关人物、模型、机构或主题。

提交前请先检索现有数据，避免重复。详细规则见 [`CONTRIBUTING.md`](./CONTRIBUTING.md)。
